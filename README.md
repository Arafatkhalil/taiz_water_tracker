Taiz Water Tracker
Taiz Water Tracker is a mobile application designed to help residents of Taiz City monitor and manage their water consumption. The app provides tools for tracking supply schedules, recording daily usage, and reviewing essential statistics to improve water management.

Features
Home overview with current water status and upcoming schedules
Daily consumption tracking with local data storage
Water pumping schedule management with customizable reminders
Interactive charts and usage analytics
Information about local water suppliers
Water-saving tips and best-practice guidelines
Customizable settings for notifications, language, and theme

Technologies Used
Flutter and Dart
SQLite and SharedPreferences
FL Chart for data visualization
Local notifications and background tasks
Localization with RTL support

Installation
Clone the repository:
git clone https://github.com/ArafatKhalil/taiz_water_tracker.git
cd taiz_water_tracker

Install dependencies:
flutter pub get

Run the application:
flutter run
